# PRD — Bot or Bluff

## 1. 产品承诺

真人与三个虚构机器人在三分钟内完成一局“间谍猜词”：描述、质疑、投票、揭晓。AI 的语言与判断是玩法核心，程序始终是唯一裁判。

## 2. 目标用户

- 想快速体验 AI 原生小游戏的普通开发者
- 想学习 Sift Issue→PR 工作流的开发者
- 想实验不同模型角色表现的开发者

## 3. MVP

- 单真人、三个机器人、其中一个卧底
- 普通阵营共享词；卧底获得相近但不同的词
- 三轮：依次描述、自由质疑、投票
- 服务端确定身份、回合、合法动作、计时和胜负
- 默认规则机器人完整可玩，无 API Key
- 一个可选 OpenAI-compatible 适配端口
- 最近十局战绩和对局揭晓
- 响应式文字聊天界面

## 4. 非目标

- 不做公共多人大厅、账号、支付或匹配系统
- 不冒充现实人物，不把 AI 席位伪装成人类
- 不保存或展示模型私有思维链
- MVP 不做实时语音，不让模型调用工具

## 5. 后续语音模式

在文字闭环稳定后添加：

1. 玩家语音输入（STT→标准文本动作）
2. AI 角色语音（标准文本事件→TTS）
3. 可打断播放、字幕、静音与无障碍回退
4. 最后才评估多人实时语音房间

语音只做输入和表现层适配，核心游戏规则保持不变。

## 6. 首次体验

`pnpm install && pnpm dev` 后，无配置即可开始一局规则机器人对战。页面应明确显示“规则机器人模式”，并提供可选模型配置入口。

## 7. 成功标准

- 新用户两分钟内开始首局
- 无 API Key 可完成完整对局
- 一局可在三分钟内结束
- 每个 AI 席位和私有信息严格隔离
- 手机宽度可完成描述、质疑与投票
- seed Issue 合并后可在界面看到变化
